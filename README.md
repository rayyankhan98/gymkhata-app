# GymKhata

A mobile app for managing a gym: members, staff, and payments.

## Features
- Google sign-in
- Roles: owner, staff, member
- Invite codes to add members
- Money and payment tracking

## Tech stack
React Native (Expo), Supabase

## Download
Android APK: see the Releases section on the right.

## Run locally
1. npm install
2. Create a .env file with your own Supabase keys
3. npx expo start
